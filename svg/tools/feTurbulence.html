<feTurbulence> Playground

Generate procedural noise patterns using Perlin noise. Creates organic textures - clouds, marble, fire, water ripples - from pure maths.

Preview

Parameters

"turbulence" - sharp, swirly patterns
"fractalNoise" - smoother, cloud-like gradients
Controls the "zoom level" of the noise. Lower = larger features.
Layers of detail. More octaves = finer detail but slower rendering.
Random seed - same settings + same seed = same pattern. Change for variety.
